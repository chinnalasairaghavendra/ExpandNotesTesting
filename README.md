# Test Automation Project

This is a comprehensive test automation framework for UI and API testing.

## Project Structure

- **tests/** - Test files organized by type (UI, API, E2E)
- **pages/** - Page object models for UI testing
- **api/** - API client and endpoint definitions
- **utilities/** - Helper functions and utilities
- **fixtures/** - Pytest fixtures for setup and teardown
- **config/** - Configuration files and environment settings
- **testdata/** - Test data in JSON format
- **reports/** - Test execution reports
- **screenshots/** - Captured screenshots during test execution
- **logs/** - Application and test logs

## Getting Started

1. Install dependencies:
   ```
   pip install -r requirements.txt
   ```

2. Run tests:
   ```
   pytest
   ```

## Features

- Page Object Model for UI tests
- REST API testing
- End-to-end testing
- Custom utilities for logging, screenshots, and retries
- Organized test data management
